3. Understand How Outdated Components Create Security Risk (A06)

Documented known vulnerabilities in legacy Werkzeug 2.2.2 (CVE-2023-25577 multipart DoS) and performed comparative software composition analysis.

4. Use OWASP ZAP as a DAST / Security-Testing Tool

Created complete testing procedure in ZAP_TESTING.md covering automated spidering, active scanning, and proxy interception against http://127.0.0.1:8080.

✅

5. Interpret Scanner Findings Instead of Blindly Trusting Them

Analyzed scanner alerts contextually, distinguishing between informational headers, high-impact logic flaws (IDOR), and actual exploitable injection points.

✅

6. Manually Validate Selected Findings in a Controlled Environment

Created step-by-step safe PoCs for IDOR parameter tampering on /orders/2 and boolean-based SQL injection on product search.

✅

7. Map Findings to OWASP Categories

Accurately mapped all weaknesses to OWASP Top 10:2021 standards (A01 Broken Access Control, A03 Injection, A05 Security Misconfiguration, A06 Outdated Components, A07 Auth Failures, A09 Logging Failures).

✅

8. Remediate Vulnerabilities

Implemented parameterized SQL queries, server-side session authorization checks, custom error sanitization, secure session flags, and HTTP security response headers.

✅

9. Retest the Application

Validated that Fixed Mode blocks all unauthorized attacks, rejects malicious payloads, and renders hardened security headers.

✅

10. Produce Evidence Showing Before vs After Security Posture

Built the live /security-report and /security-lab dashboards with structured investigation cards and side-by-side matrices for college lab presentation.
